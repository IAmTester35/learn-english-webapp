# HSK 试卷编写指南：L TestLab 汉语考试命题规范

本指南专为**汉语考试命题教师、教研人员及试题编写者**制定，详细说明如何依据中国教育部中外语言交流合作中心颁布的**汉语水平考试（HSK）**以及**汉语水平口语考试（HSKK）**标准，使用系统标准 JSON 格式编写听力、阅读、口语和书写四项技能的综合考试试卷。

---

## 1. 试卷概览与元数据 (Test Overview & Metadata)

每套试卷均以独立的 JSON 文件形式存储。试卷根对象包含基本信息，并将题目内容划分为四个标准技能模块：

```json
{
  "schemaVersion": "1.0",
  "id": "hsk2-elementary-chinese-test-01",
  "title": "HSK 2 级初级汉语综合能力考试",
  "description": "全面评估 HSK 2 级水平（掌握约 300 常用词）考生的阅读、听力、口语和书写四项语言技能。",
  "sections": {
    "reading": { ... },
    "listening": { ... },
    "speaking": { ... },
    "writing": { ... }
  }
}
```

### 概览字段说明

| 字段名称 (Key)   | 数据类型 | 必填 | 编写说明                                                                                                       |
| :-------------- | :------- | :--- | :------------------------------------------------------------------------------------------------------------- |
| `schemaVersion` | `string` | 是   | 固定填写 `"1.0"`。                                                                                             |
| `id`            | `string` | 是   | 试卷全局唯一标识符，统一采用小写中划线格式（kebab-case，如 `hsk2-test-01`、`hsk4-mock-02`）。JSON 文件命名须与该 ID 一致。 |
| `title`         | `string` | 是   | 试卷正式名称，面向考生展示（如 `"HSK 3 级中级汉语能力测评卷"`）。                                                |
| `description`   | `string` | 是   | 简述考试等级、考察词汇量标准、适用人群及能力考察重点。                                                        |
| `sections`      | `object` | 是   | 试卷的四项技能模块容器，必须完整包含 `reading`、`listening`、`speaking` 和 `writing`。                            |

## 2. 试卷结构与 HSK 等级指标蓝图 (Exam Structure & Blueprint)

为确保命题信度与效度，避免试卷难度脱节或考生认知过载，请严格按照目标 HSK 等级的词汇量、篇章字数和音频时长进行命题设计：

| HSK 等级   | 词汇量标准   | 阅读理解模块 (`reading`)                                                  | 听力理解模块 (`listening`)                                                | 口语表达模块 (`speaking` - 参照 HSKK)                   | 书写表达模块 (`writing`)                                              | 建议考试总时长 |
| :--------- | :----------- | :------------------------------------------------------------------------ | :------------------------------------------------------------------------ | :------------------------------------------------------ | :-------------------------------------------------------------------- | :------------- |
| **HSK 1 级** | 约 150 词    | **4 篇短对话/短文**<br>• 每篇 40–80 字<br>• 总题量 15–20 题               | **4 段简短录音**<br>• 每段 30–50 秒（约 50–80 字）<br>• 总题量 15–20 题   | **2 个任务** (HSKK 初级)<br>• 自我介绍<br>• 基础问答    | **2 个任务**<br>• 拼音写汉字/补全句子<br>• 简单造句（10–20 字）       | 约 45 分钟     |
| **HSK 2 级** | 约 300 词    | **4 篇生活短文/对话**<br>• 每篇 80–150 字<br>• 总题量 20 题               | **4 段日常场景录音**<br>• 每段 45–90 秒（约 80–130 字）<br>• 总题量 20 题 | **2 个任务** (HSKK 初级)<br>• 个人情况介绍<br>• 日常叙事 | **2 个任务**<br>• 日常留言/便条（30–50 字）<br>• 看图写微故事（60–80 字）| 约 60 分钟     |
| **HSK 3 级** | 约 600 词    | **3–4 篇叙事短文**<br>• 每篇 180–300 字<br>• 总题量 18–24 题              | **3–4 段中速录音**<br>• 每段 1.5–2.5 分钟（180–280 字）<br>• 16–20 题    | **2 个任务** (HSKK 初/中级)<br>• 情景应答<br>• 简要谈看法| **2 个任务**<br>• 实用通知/邮件（80–100 字）<br>• 叙事段落（100–120 字）| 约 80 分钟     |
| **HSK 4 级** | 约 1,200 词  | **3–4 篇实用短文/说明文**<br>• 每篇 300–450 字<br>• 总题量 18–24 题       | **3–4 段长对话/讲话**<br>• 每段 2–3.5 分钟（300–450 字）<br>• 16–20 题   | **2–3 个任务** (HSKK 中级)<br>• 看图说话<br>• 话题辩析  | **2 个任务**<br>• 词语造句/按序组句<br>• 主题短文（120–160 字）        | 约 95 分钟     |
| **HSK 5 级** | 约 2,500 词  | **3–4 篇报刊/议论文**<br>• 每篇 450–700 字<br>• 总题量 18–24 题           | **3–4 段专题访谈/广播**<br>• 每段 3–4 分钟（450–650 字）<br>• 16–20 题    | **2–3 个任务** (HSKK 高级)<br>• 听后复述<br>• 论述表达  | **2 个任务**<br>• 给定 5 个词编写短文（80 字）<br>• 看图写作（150–200 字）| 约 115 分钟    |
| **HSK 6 级** | 5,000 词以上 | **3–4 篇学术/文化/哲理长文**<br>• 每篇 700–1000 字<br>• 总题量 18–24 题   | **3–4 段长篇讲座/学术报告**<br>• 每段 3.5–5 分钟（600–900 字）<br>• 16–20 题 | **2–3 个任务** (HSKK 高级)<br>• 观点深度阐述与辩护     | **1–2 个任务**<br>• 阅读 1,000 字叙事长文后缩写为 400 字短文           | 约 130 分钟    |

### 命题基本准则

1. **题目密度控制：** 每篇阅读短文或听力材料设计 **4 至 6 道题目**（较长高级篇章最多不超过 8 题），兼顾考察面与作答节奏。
2. **朗读语速与节奏标准：**
   - **HSK 1–2 级：** 慢速、清晰，每分钟约 100–120 汉字，字正腔圆，停顿充分。
   - **HSK 3–4 级：** 中速，每分钟约 140–180 汉字，语流自然，符合日常口语语调。
   - **HSK 5–6 级：** 正常母语语速，每分钟约 200–240 汉字，语气生动，包含自然连读和重音。
3. **文字规范与标点符号：**
   - 全卷使用规范**简体汉字**。
   - 标点符号统一使用中文全角标点：逗号 `，`、句号 `。`、顿号 `、`、冒号 `：`、问号 `？`、叹号 `！`、双引号 `“”`、书名号 `《》`、省略号 `……`。
   - HSK 1–2 级若涉及超纲词或初学者过渡，可在题干提供拼音标注；HSK 3 级及以上全卷不出现拼音。

## 3. 标准题型规范（阅读与听力）

阅读和听力模块支持四种标准化题型。

### 核心规则

- **全局唯一题号 (`id`)：** 全卷每道题目的 `id` 必须全卷唯一（如阅读题使用 `r-q1`、`r-q2`；听力题使用 `l-q1`、`l-q2`）。严禁重复。
- **详尽答案解析 (`explanation`)：** 必须引用原文句子明确说明判断依据。解析将在交卷后展示给考生以辅助复习。

---

### 3.1. 单项选择题 (`multiple_choice`)

标准单项选择，四个选项中选出一个正确答案。

```json
{
  "id": "r-q1",
  "type": "multiple_choice",
  "prompt": "星期六李明常常做什么？",
  "options": [
    { "id": "A", "text": "去公司上班" },
    { "id": "B", "text": "在家里休息" },
    { "id": "C", "text": "去北京旅行" },
    { "id": "D", "text": "去饭馆吃饭" }
  ],
  "correctAnswer": "B",
  "explanation": "第一段明确提到：“星期六不上班，我常常在家里休息。”因此选 B。"
}
```

- `options`: 提供 3 到 4 个选项，每个选项包含标识符 `id`（如 `"A"`、`"B"`、`"C"`、`"D"`）及展示文本 `text`。
- `correctAnswer`: 必须严格与正确选项的 `id` 一致。

---

### 3.2. 多项选择题 (`multiple_select`)

考生须从选项中选择两个或两个以上的正确选项。

```json
{
  "id": "r-q2",
  "type": "multiple_select",
  "prompt": "根据第二段，小王准备了哪两样东西？（请选择两个正确答案）",
  "options": [
    { "id": "A", "text": "雨伞" },
    { "id": "B", "text": "照相机" },
    { "id": "C", "text": "自行车" },
    { "id": "D", "text": "地图" }
  ],
  "correctAnswers": ["A", "B"],
  "explanation": "第二段明确写道：“他把雨伞和照相机放进了包里。”因此正确答案为 A 和 B。"
}
```

- `correctAnswers`: 所有正确选项 `id` 构成的数组（如 `["A", "B"]`）。
- **计分规则：** 系统采用**全对才得分**机制（不设漏选半分）。题干中必须明确注明所需选取的数量（例如：_“哪两项……”_、_“选出两个正确答案”_）。

---

### 3.3. 填空题 (`fill_blank`)

用于考察关键词听写、阅读提取或语法填空。

```json
{
  "id": "r-q3",
  "type": "fill_blank",
  "prompt": "哈尔滨白天是零下________度。",
  "acceptedAnswers": [
    "十五",
    "15"
  ],
  "caseSensitive": false,
  "explanation": "文中明确写道：“白天的温度是零下十五度。”"
}
```

- `acceptedAnswers`: 必须穷举**所有应予给分的合规写法**：
  - 中文大写/汉字数字与阿拉伯数字：`["十五", "15"]`、`["二", "两", "2"]`。
  - 常见同义词或简称：`["西红柿炒鸡蛋", "番茄炒蛋", "西红柿炒蛋"]`。
  - 带/不带量词：`["两碗", "两碗米饭"]`。
- `caseSensitive`: 汉语考试统一设为 `false`。

---

### 3.4. 判断题 (`true_false_ng`)

用于考察考生对短文或对话细节的判定能力。

```json
{
  "id": "r-q4",
  "type": "true_false_ng",
  "prompt": "李明下午常常一个人去公园跑步。",
  "correctAnswer": "FALSE",
  "explanation": "文章说明李明是早上去公园跑步，下午常常去商店买东西或在家看电影，故陈述错误。"
}
```

- `correctAnswer`: 必须是以下三个全大写字符串之一：`"TRUE"`（正确）、`"FALSE"`（错误）、`"NOT_GIVEN"`（未提及）。
- **注意：** 该题型**不可**编写 `options` 字段，考试界面会自动渲染标准的“正确 / 错误 / 没提到”按钮。

---

## 4. 阅读理解部分 (`reading`)

阅读模块包含考生答题指引及一篇或多篇阅读文本：

```json
"reading": {
  "instructions": "请仔细阅读下面的短文，回答 r-q1 到 r-q8 的问题。",
  "passages": [
    {
      "id": "r-p1",
      "title": "我的周末生活",
      "content": "我叫李明，今年二十三岁，在北京工作。星期六不上班，我常常在家里休息。早上我八点半起床，吃了早饭以后，去附近的公园跑步。\n\n下午我有时候和朋友一起去商店买东西，有时候在家看电影。晚上我喜欢做中国菜，我最会做的菜是西红柿炒鸡蛋。我觉得周末的时间过得很快。",
      "questions": [
        /* 本篇短文对应的题目数组 */
      ]
    }
  ]
}
```

### 编写规范

- `id`: 使用清晰的顺序编号（如 `r-p1`, `r-p2`）。
- `title`: 填写简明的中文篇名（如 `"在饭馆点菜"`, `"哈尔滨的冬天"`）。系统在渲染时会自动追加序号。
- `content`: 输入阅读正文。段落之间使用双换行符（`\n\n`）以确保良好的段落排版。
- `questions`: 归属于该篇短文的所有题目必须直接置于其 `questions` 数组内。

## 5. 听力理解部分 (`listening`) 与语音合成 (Audio Design)

命题者仅需编写听力对话文本、指定说话人角色和语速，**无需自行录制音频或上传音频文件**。系统将自动调用 Google Gemini 语音引擎生成地道标准的普通话考试音频。

```json
"listening": {
  "instructions": "听录音，回答 l-q1 到 l-q6 的问题。每段录音播放两遍。",
  "parts": [
    {
      "id": "l-p1",
      "title": "在饭馆点菜",
      "audioConfig": {
        "scenario": "everyday_dialogue",
        "accent": "standard",
        "pacing": "slow",
        "overallStyle": "标准普通话，发音清晰，日常生活语调，适合 HSK 2 级考生"
      },
      "speakers": [
        {
          "name": "FuWuyuan",
          "gender": "female",
          "voiceName": "Aoede",
          "style": "热情、礼貌、语速适中"
        },
        {
          "name": "KeRen",
          "gender": "male",
          "voiceName": "Puck",
          "style": "自然、平静"
        }
      ],
      "transcript": "FuWuyuan: 您好，请问您几位？\nKeRen: 两个人。我们想坐在窗户旁边，可以吗？\nFuWuyuan: 可以，请这边走。这是菜单，您想吃什么？\nKeRen: 我要一个宫保鸡丁，一个西红柿鸡蛋汤。你们这儿有米饭吗？\nFuWuyuan: 有，米饭一碗两块钱。您要几碗？\nKeRen: 两碗。再来一瓶可乐，不要冰的。\nFuWuyuan: 好的，请稍等。",
      "questions": [
        /* 本音频对应的题目数组 */
      ]
    }
  ]
}
```

> [!NOTE]
> **听力文本保密机制：** `transcript` 字段仅在服务端用于驱动语音引擎合成音频，**在考试作答过程中绝对不会向考生透露**，确保纯粹考察考生的听力理解能力。

---

### 5.1. 听力文本编写要求

1. **角色台词格式：** 说话人名称与台词之间必须采用**半角冒号加空格**（`Speaker: Text`），说话人建议使用英文字母或拼音标识（如 `LiMing: `、`FuWuyuan: `、`Teacher: `），以保证后台语音引擎稳定解析多角色分轨。
2. **独白与广播通知：** 车站广播、天气预报等单人独白，可使用 `Announcer: ...` 或直接连续书写。
3. **中文韵律与自然语气词：**
   - 适当使用中文叹词和语气助词（如“啊”、“吧”、“呢”、“哎呀”、“嗯”、“好的”），增强口语真实度。
   - 使用破折号 `——` 或省略号 `……` 表示思考或迟疑。

---

### 5.2. 语音合成情感事件标签 (Gemini TTS Vocal Events)

语音引擎支持在中文台词中直接嵌入尖括号标签 `<...>`，以模拟真实母语者的口语反应和情感起伏：

| 分类 | 支持标签 | 适用 HSK 听力情景 |
| :--- | :--- | :--- |
| **笑声与喜悦** | `<laugh>`, `<chuckle>`, `<giggle>`, `<snicker>` | 朋友聚会、轻松幽默的日常对话（HSK 2–4 级常见）。 |
| **呼吸与释怀** | `<breath>`, `<heavy breath>`, `<sigh>`, `<gasp>`, `<pant>` | 赶上列车后的松一口气、听到意外消息时的惊讶、叹气。 |
| **真实生理反应** | `<cough>`, `<throat-clearing>`, `<yawn>`, `<whisper>` | 教师上课前的清嗓子、生病就医场景中的咳嗽、轻声细语。 |
| **精准时间停顿** | `<short pause>`, `<long pause>` | 语句间刻意留出的思考停顿，比常规标点更具节奏感。 |

#### 范例：

```text
KeRen: 哎呀！我忘了带钱包。<sigh>
FuWuyuan: 没关系，您也可以用手机扫码支付。<chuckle>
KeRen: 太好了……<short pause> 谢谢你！
```

#### 语音标签与舞台提示的区别：
- **尖括号 `<tag>`：** 属于语音发声事件，直接嵌入在台词中，说话人会真实发出相应声音。
- **方括号 `[Effect]`：** 属于环境音效提示（如 `[汽车喇叭声]`、`[下课铃声]`）。**必须单独占用一行**，语音引擎会自动识别并跳过，不会被误读为台词。

---

### 5.3. 音频环境与语速配置 (`audioConfig`)

| 属性名称 (Key) | 可选值 (Value)        | 适用 HSK 考试场景                                                              |
| :------------- | :-------------------- | :----------------------------------------------------------------------------- |
| `scenario`     | `everyday_dialogue`   | 日常会话：点餐、购物、问路、租房、同学闲聊（HSK 1–3 级常用）。                 |
|                | `public_announcement` | 公共广播：高铁站检票、地铁报站、机场登机广播、学校通知。                       |
|                | `interview`           | 采访访谈：职场面试、电台访谈、学者对话（HSK 4–5 级）。                          |
|                | `academic_lecture`    | 学术讲座：大学课堂、科普演讲、历史文化介绍（HSK 5–6 级）。                      |
|                | `group_discussion`    | 小组讨论：多名学生或同事研讨课题、方案权衡（HSK 4–6 级）。                      |
|                | `news_broadcast`      | 正式新闻播音：央视/电台新闻通报、天气预报、经济分析（HSK 5–6 级）。            |
| `accent`       | `standard`            | **标准普通话**（HSK 考试一律选用 `"standard"`）。                              |
| `pacing`       | `slow`                | 慢速：发音字正腔圆，句间停顿充足（HSK 1–2 级初学者）。                         |
|                | `moderate`            | 中速：标准自然会话语速（HSK 3–4 级中级考生）。                                  |
|                | `fast`                | 快速：母语者自然日常口语与快速连读（HSK 5–6 级高级考生）。                      |
|                | `exam_standard`       | 考试标准速：吐字清晰，语调平稳，节奏严谨。                                      |
| `overallStyle` | 自定义文本            | 给语音合成引擎的导演指导词（如 `"标准普通话，语速平稳，发音清晰，适合HSK2级"`）。|

### 5.4. 发音人配置与角色音色 (`speakers`)

## 8. 命题审校质量清单 (Exam Author Quality Checklist)

在试卷正式入库前，请命题组对照以下检查清单完成终审：

1. [ ] **HSK 等级词汇严格达标：** 试卷阅读短文、听力材料的词汇与语法点严格受控在目标等级大纲范围之内，无生僻超纲词干扰。
2. [ ] **字数与语速符合蓝图：** 阅读篇章字数、听力材料字数与语速（字/分钟）严格符合第 2 节对应 HSK 等级的蓝图规范。
3. [ ] **全卷题号全局唯一：** 所有题目的 `id`（如 `r-q1`, `l-q1`, `s-t1`, `w-t1`）在全卷范围内无任何重复。
4. [ ] **全角标点与角色格式：**
   - 正文与题干全角标点无误（`，` `。` `、` `：` `？` `！` `“”` `《》`）。
   - 听力对话统一使用半角冒号格式（如 `LiMing: `、`FuWuyuan: `）。
5. [ ] **客观题答案键核验：**
   - 单选与多选题的 `correctAnswer` / `correctAnswers` 均能严格在 `options` 选项列表中找到对应的 `id`。
   - 多选题题干中已明确写明需选取的项数（如“哪两项……”）。
   - 判断题的 `correctAnswer` 仅限 `TRUE`、`FALSE` 或 `NOT_GIVEN` 三种大写枚举值，且未配置 `options` 列表。
   - 填空题的 `acceptedAnswers` 充分穷举了汉字数字与阿拉伯数字（如 `"十五"` 与 `"15"`）及合理同义词。
6. [ ] **语音合成配置合规：**
   - `accent` 统一配置为 `"standard"`。
   - `pacing` 根据级别设定（HSK 1–2 为 `"slow"`，HSK 3–4 为 `"moderate"`，HSK 5–6 为 `"fast"`）。
   - 尖括号语音事件标签（如 `<chuckle>`, `<sigh>`, `<short pause>`）使用自然，未出现乱码。
7. [ ] **主观题评分标准清晰：** 口语（HSKK）与书写任务均提供了完备的 4 维度 Rubric 及标准高分参考范文（`sampleAnswer`）。
